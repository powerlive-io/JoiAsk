---

JoiAsk 支持话题分类、图文投稿、内容审核与卡片归档。推荐使用 Docker 部署，镜像为 `ghcr.io/powerlive-io/joiask:latest`。

<Callout type="warn" title="新安装没有默认管理员或默认密码">
  首次部署需要填写 Session 密钥，并通过离线 CLI 创建超级管理员，见 [快速开始](./guide/quick-start.mdx)。
</Callout>
