---
title: "快速开始"
---

推荐使用 Docker 部署 JoiAsk。容器包含前端、管理后台、后端与 Caddy，只需对外开放一个端口。

## 1. 准备 Session 密钥

镜像自带 SQLite 和本地图片存储配置，不含任何密钥。首次部署运行以下命令一次，将结果保存在密码管理器或部署平台的 Secret 中，以 `JOIASK_SESSION_SECRET` 传给容器。不要把真实密钥写入命令或仓库。

```bash
openssl rand -hex 32
```

已有部署请保留原密钥，不要每次启动重新生成。使用 MySQL、OSS 或其他自定义配置时，可继续挂载自己的 `config.json`。不设置环境变量时，仍使用文件中的 `security.session_secret`；显式传入空值或无效值会导致启动失败。详见 [配置参考](./configuration.mdx)。

## 2. 启动容器

**新安装没有默认管理员或默认密码。**

若要在首次启动时创建超级管理员，请在部署平台设置 `JOIASK_INITIAL_ADMIN_USERNAME`，并将 `JOIASK_INITIAL_ADMIN_PASSWORD` 作为 Secret 注入容器。使用独立的强密码（单行，最多 4096 字节）。使用 `docker run` 时，可以先在宿主机环境中安全设置这两个变量，再将 `-e JOIASK_INITIAL_ADMIN_USERNAME -e JOIASK_INITIAL_ADMIN_PASSWORD` 加到下面命令的镜像名前，不需要在命令中写出密码。

新站点未提供这两个值时不会创建管理员，只提供一项则启动失败；补齐后重试即可。已有站点或已通过 CLI 建过管理员的数据库会忽略这些变量。初始化成功后可从部署配置移除两项并重建容器，保留原数据卷；更改环境变量不会重置密码。

以下命令假设宿主机环境已导出保存好的 `JOIASK_SESSION_SECRET`：

```bash
docker run -d --restart always \
    --name joiask \
    -p 80:80 \
    -e JOIASK_SESSION_SECRET \
    -v $(pwd)/data:/work/db \
    -v $(pwd)/uploads:/work/frontend/public/upload-img \
    ghcr.io/powerlive-io/joiask:latest
```

数据库与上传目录必须持久化挂载，避免数据随容器删除而丢失。使用自定义配置时，在镜像名前添加 `-v "$(pwd)/config.json:/work/config/config.json:ro"`；若密钥来自文件，同时省略 `-e JOIASK_SESSION_SECRET`。

## 3. 创建管理员

如果已通过环境变量创建管理员，直接跳到第 4 步。否则，使用离线 CLI 创建：先停止所有连接此数据库的后端实例，再使用同版本镜像操作。在宿主机的 **Bash** 中执行以下命令，输入不会回显，也不会把密码放进命令参数、环境变量或 shell 历史。不要开启 `set -x`，不要用明文密码替换变量。`owner` 是自选用户名，可自行更换：

```bash
docker stop joiask
(
    set +x
    unset joiask_password
    IFS= read -r -s -p 'New administrator password: ' joiask_password || exit 1
    printf '\n' >&2
    builtin printf '%s\n' "$joiask_password" |
        docker run --rm -i --workdir /work --entrypoint /work/jask \
            -v "$(pwd)/data:/work/db" \
            ghcr.io/powerlive-io/joiask:latest admin create owner
)
# 确认上面的命令成功后：
docker start joiask
```

`docker run` 使用 `-i` 传递标准输入，**不要加 `-t`**。以上示例使用镜像内置配置；如果服务使用自定义配置，CLI 也必须添加同一配置文件挂载并连接同一数据库。离线 CLI 不需要 Session 密钥，不会启动前端、Caddy 或 HTTP 服务。

## 4. 访问服务

容器只暴露一个端口（80），内部 Caddy 自动处理路由：

- 前端提问箱：`http://localhost/`
- 管理后台：`http://localhost/admin`
- 后端 API：`http://localhost/api/`

用上一步创建的超级管理员账号登录后台。角色分为超级管理员（`super_admin`）和管理员（`admin`）：两者拥有相同的业务和站点配置权限，只有超级管理员可以管理后台管理员账号及角色。用户名本身不代表权限。

公网部署请继续阅读 [HTTPS 反向代理](./deployment.mdx#使用-nginx-反向代理https) 与 [安全配置](./configuration.mdx#session-与-b-站验证安全配置)。
