# 故障排查

## 查看容器日志

```bash
docker logs joiask
```

## 进入容器调试

```bash
docker exec -it joiask bash
```

## 容器启动后无法访问

- 检查端口是否被占用：`netstat -tlnp | grep 80`。
- 检查防火墙设置。
- 查看容器日志：`docker logs joiask`。
- 如果提示 Session 密钥无效，检查实际挂载的配置文件，按 [安全配置](./configuration.md#session-与-b-站验证安全配置) 填写有效密钥。不要每次重启都重新生成密钥。

## 图片上传失败

- 检查存储目录是否正确挂载。
- 如果使用 OSS，检查 access_key 和 bucket 配置。
- 查看后端日志确认错误信息。
- 上传格式、体积限制与历史文件检查见 [上传文件安全](./upload-serving-security.md)。

## 数据丢失

- 确保数据库文件和上传目录已正确挂载到宿主机。
- 使用 `-v` 参数挂载目录，避免数据随容器删除而丢失。
- 管理员恢复命令必须连接原数据库。不要另挂空目录来「恢复」。

## 无法登录管理后台

新安装没有默认管理员。首次部署先 [创建管理员](./quick-start.md#_3-创建管理员)；忘记密码或没有超级管理员时，使用 [管理员恢复流程](./administrators.md)。

## 无法使用邮箱找回密码

检查后台是否开启邮件功能、SMTP 配置是否正确，以及用户邮箱是否已经绑定并确认。邮件链接有效期为 30 分钟且只能使用一次，详见 [邮箱绑定与密码找回](./usage.md#邮箱绑定与密码找回)。
